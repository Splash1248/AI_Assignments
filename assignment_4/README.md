# Assignment 2

Python implementations of Constraint Satisfaction Problem (CSP) algorithms.

Before running any of the codes, navigate into this folder.

```bash
cd assignment_4
```

## Files Overview
* `CSP.py`: Core Constraint Satisfaction Problem solver used by all scripts.
* `districts.geojson`: Geographic boundary data for the Telangana map.
* `q1_australia.py`: Solves the map coloring problem for Australian states.
* `q2_telanganaDistricts.py`: Colors and plots the 33 districts of Telangana.
* `q3_sudoku.py`: Solves the given 9x9 Sudoku puzzle constraint problem.
* `q4_cryptanalysis.py`: Solves the TWO + TWO = FOUR cryptarithmetic equation.

## Installation
Install the required packages for the Q2 map visualization:

```bash
pip install geopandas matplotlib
```

## How to Run
Execute each script individually from your terminal:

```bash
python q1_australia.py
python q2_telanganaDistricts.py
python q3_sudoku.py
python q4_cryptanalysis.py
```
